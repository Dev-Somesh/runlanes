Shared files

Runs on the left, files two or more of them touched on the right — including across runners that are live on this project together. Edges are observed from the transcripts, not declared. Files only one run touched are that run's own territory and are listed with it instead. A path a shell command named without settling what it did is drawn as contact and listed with the run as not established, because a pattern confident enough to call git checkout -- file a write would invent collisions that never happened. A file in red is a collision rather than contact: two runs both wrote it while both were running, so neither was working from a settled file. Which edit survived is a question for git — this says only that they were on the same ground at the same time.
